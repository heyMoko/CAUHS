# CAUHS

### 직원출장 및 지출결의 내역 대시보드

중앙대학교병원 직원의 출장·교육비 예산과 지출 현황, 환급 증빙 제출 상태를 한눈에 살펴보는 행정 대시보드입니다. 기존 Excel 업무 자료를 분석해 부서별 예산 현황과 영수증·이수증 누락 내역을 빠르게 확인할 수 있도록 돕습니다.

## 주요 기능

- Excel 교육·예산 자료 분석 및 현황 시각화
- 부서별 확정예산, 등록 교육비, 잔액 조회
- 영수증·이수증 누락 직원 및 교육 내역 검색·정렬
- 이름, 사번, 교육명, 연락처 기준 조회
- 조회 결과 CSV 내보내기
- 마지막 업로드 자료와 화면 테마의 브라우저 내 저장

## 기술 스택

| 영역 | 기술 |
| --- | --- |
| UI | React 19, TypeScript |
| 빌드 | Vite 6 |
| Excel 분석 | ExcelJS |
| 아이콘 | Lucide React |
| 호스팅 | Cloudflare Workers Static Assets |

## 데이터 처리

Excel 파일은 브라우저 안에서 분석합니다. 마지막 업로드 데이터는 동일한 브라우저와 사이트 주소에서 다시 사용할 수 있도록 IndexedDB에 저장하며, 애플리케이션 서버나 외부 데이터베이스로 전송하지 않습니다. 서버 기반 공동 사용 기능은 현재 범위에 포함하지 않습니다.
