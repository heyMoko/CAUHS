# CAUHS 교육예산 관리 · Sprint 1

엑셀 파일로 부서별 예산과 교육 서류 빈칸을 조회하는 로컬 MVP입니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상 환경에서 실행합니다.

```sh
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 처음에는 **가상 예시 데이터**가 보입니다. 엑셀 업로드 버튼으로 실제 파일을 선택하면 즉시 교체됩니다.

```sh
npm run test
npm run build
```

실제 파일 검증 테스트는 환경 변수 `CAUHS_TEST_XLSX`에 로컬 원본 경로를 지정한 경우에만 실행됩니다. 원본 파일은 저장소에 포함하지 않습니다.

## 포함 기능

- .xlsx 선택·드래그 업로드, 파일 내 시트와 헤더로 데이터 연결
- 부서별 확정예산·등록 교육비·잔액·소진율
- 영수증 또는 이수증이 **빈칸**인 교육을 모두 표시 (예정 교육·문자 교육비 포함)
- 이름·사번·교육명·전화번호 검색·정렬, 예산부서·교육구분 필터, 페이지 이동
- 이름·사번·교육명·연락처·서류 상태·원본 위치 확인
- 조회 결과 CSV 내보내기 (Excel 호환 UTF-8 BOM)
- 업로드 검토 항목, 같은 파일 재업로드 시 전체 교체
- 모바일 화면 지원

## 데이터 처리 원칙

- 파일은 ExcelJS로 브라우저에서 읽고, 마지막 업로드의 정리된 데이터는 해당 브라우저의 IndexedDB에 저장합니다. 원본 엑셀은 서버로 전송하지 않습니다.
- IndexedDB 데이터는 같은 브라우저·기기·사이트 주소에서만 복원됩니다. 브라우저 저장공간을 지우거나 다른 기기를 쓰면 다시 업로드해야 합니다. 화면의 저장 데이터 삭제로 직접 지울 수 있습니다.
- 실제 직원 정보나 원본 파일을 저장소에 넣지 않습니다. Git에서 엑셀·CSV·환경변수 파일을 제외합니다.
- 새로고침하면 마지막 업로드 데이터가 IndexedDB에서 복원됩니다. 처음 방문하거나 저장 데이터를 삭제한 경우 가상 예시가 보입니다.
- 서류 빈칸은 null·빈 문자열·공백입니다. `해당없음`, `예산 이관`, `△` 등의 원문은 빈칸으로 바꾸지 않습니다. 명시적 X 역시 빈칸 필터에는 포함하지 않습니다.
- 동일 직원도 교육마다 한 행으로 표시합니다. 교육 건수와 고유 사번 수를 구분합니다.
- 숫자 사번은 5자리 문자열로 정규화하고 영문 사번은 그대로 보존합니다. 휴대폰 → 전화번호 → 내선 순으로 표시합니다.
- 예산은 오른쪽 집계표의 M(부서)·O(원 단위 금액)를 읽습니다. L열 행 어긋남과 연구행정관리팀/연구윤리팀 분할을 고려합니다.
- 등록 교육비는 교육 내역의 숫자 교육비 합계입니다. 실제 환급 완료액이 아닙니다. 문자 교육비는 금액 합계에 넣지 않습니다.
- 교육행정팀 예산은 원본 내 기준 차이가 있어 위탁 합계에서 기본 제외합니다. 부서별 예산 화면에서 참고용으로 포함할 수 있습니다.
- 2026 원본 양식을 우선 지원합니다. 시트명 공백·밑줄 차이는 허용합니다.

## 저장소와 향후 배포

Git 원격 저장소: https://github.com/heyMoko/CAUHS

Cloudflare Workers 정적 에셋으로 배포하며, `wrangler.jsonc`가 빌드된 `dist/`를 배포합니다. 이 저장 방식은 사용자의 브라우저에만 데이터를 보관하고 서버 DB는 사용하지 않습니다. 여러 직원이 같은 최신 파일을 공유해야 하는 경우에는 개인정보·접근권한·보존정책을 검토한 뒤 서버/DB를 별도로 연결해야 합니다.

## 알려진 한계

- 실제 서류 첨부물·지급 완료 여부를 검증하지 않습니다.
- 파일 내 수식은 재계산하지 않고 저장된 결과를 읽습니다. 사용금액은 원자료에서 독립적으로 재합산하여 대조합니다.
- Google Fonts 스타일시트를 요청할 수 있으며, 직원 데이터는 요청에 포함하지 않습니다. 연결 불가 시 시스템 글꼴로 표시됩니다.
- 브라우저 파일 분석에는 메모리가 필요하므로 30MB까지 허용합니다.
